# 🍴 구성원 식사 여론조사 서비스 (Meal Poll Service)

> **Flask와 SQLite를 기반으로 구성원들의 식사 시간대별 메뉴 제안 및 실시간 투표를 지원하는 웹 애플리케이션입니다.** > 매번 번거로웠던 점심/저녁 메뉴 소통 과정을 디지털화하여, 구성원들이 직접 메뉴를 등록하고 투표 및 돌림판 기능을 통해 실시간으로 조율할 수 있도록 제작되었습니다.

---

## 🌟 주요 기능 (Key Features)

- **🔐 이름 기반 동적 멤버 등록 및 로그인 시스템**
  - 사전에 등록된 구성원(`홍길동` 등)은 즉시 로그인이 가능합니다.
  - 신규 구성원은 메인 화면의 슬라이딩 패널 전환을 통해 실시간으로 이름을 등록한 후 즉시 서비스를 이용할 수 있습니다.
- **📅 날짜 및 시간대별 세부 조회**
  - 원하는 날짜와 식사 시간대(아침/점심/저녁)를 선택하여 실시간으로 등록된 메뉴 목록을 조회합니다.
- **📝 메뉴 제안 및 실시간 CRUD**
  - 구성원이 원하는 메뉴 종류(배달, 외식, 구내식당 등)와 메뉴 이름, 한줄 메모를 작성해 투표 후보에 올릴 수 있습니다.
  - 자신이 올린 제안은 실시간으로 수정 및 삭제가 가능합니다.
- **📊 실시간 투표 (Vote) 시스템**
  - 다른 구성원이 등록한 메뉴 추천 리스트를 확인하고 마음에 드는 메뉴에 투표할 수 있습니다.
- **🔮 결정 장애 해결을 위한 '메뉴 돌림판'**
  - 후보가 많아 결정하기 힘들 때, 등록된 메뉴들을 기반으로 랜덤 추첨을 진행하는 실시간 룰렛 애니메이션 기능을 제공합니다.

---

## 🛠️ 기술 스택 (Tech Stack)

- **Backend:** Python 3.12, Flask
- **Database:** SQLite3
- **Frontend:** HTML5, CSS3 (Animate.css 라이브러리 활용), JavaScript (jQuery)
- **Environment Management:** Python-dotenv

---

## 📂 프로젝트 디렉터리 구조 (Directory Structure)

Flask 표준 정적 파일 매핑 규칙에 맞춘 깔끔하고 직관적인 디렉터리 구조입니다.

whats_for_dinner
├── app.py                  # Flask 백엔드 서버 및 API 엔드포인트 핵심 로직
├── hancom_food_db.db       (실행 시 자동 생성되는 SQLite 데이터베이스 파일)
├── .gitignore
├── .env                    # 비밀키 등 환경변수 관리 파일
├── templates/              # HTML 템플릿 폴더
│   ├── login.html          # 가로·세로 정중앙 정렬 및 슬라이딩 패널이 적용된 로그인/등록 화면
│   └── menu.html           # 메뉴 등록, 투표 및 돌림판이 위치한 메인 대시보드 화면
└── static/                 # CSS 및 JavaScript 정적 파일 폴더
    ├── style.css           # 로그인/등록 화면 전용 스타일시트
    ├── script.js           # 로그인 폼 비동기 전환 및 라우팅 스위칭 자바스크립트
    ├── menu.css            # 메인 대시보드 및 룰렛 컴포넌트 전용 스타일시트
    └── menu.js             # 데이터 실시간 비동기 통신(Fetch API) 및 룰렛 애니메이션 로직
